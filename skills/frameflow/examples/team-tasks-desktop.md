# Team Tasks

- kind: desktop
- client: Operations team
- about: A desktop app where a small team shares tasks and marks them done.
- version: 3
- status: draft
- date: 2026-10-06

## Finishing a task
From opening the app to a task marked done.

1. Sign in [form]: Types the work email and password, clicks "Sign in". → 2
   ! Account locked: Sees "Ask your manager to unlock it". → end
2. My tasks [list]: Sees today's tasks, clicks one. → 3
3. Task [detail]: Reads the details and the notes, clicks "Mark done". → 4
4. Done [done]: Sees the task move to "Finished today". → 2
5. Weekly report [message]: Sees the week's finished tasks, from the menu. → end
